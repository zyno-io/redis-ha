# Redis

Three-member Redis/Sentinel with unattended recovery and synchronized rolling
handoff. Runtime scripts are included in this chart; an external lifecycle
ConfigMap is not required.

See the [installation, configuration, migration and release guide](https://github.com/zyno-io/redis-ha/blob/main/README.md)
and [exact lifecycle contract](https://github.com/zyno-io/redis-ha/blob/main/docs/lifecycle.md).
